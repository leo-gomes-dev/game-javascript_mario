# 🎮 Mario Game — JavaScript

Um jogo simples inspirado no universo clássico do Mario, desenvolvido com **HTML, CSS e JavaScript puro**.

O projeto foi criado com foco em aprendizado e prática de conceitos fundamentais de desenvolvimento web, como manipulação do DOM, eventos, animações com CSS e lógica de programação com JavaScript.
